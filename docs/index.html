怎么学

不打红叉，
只写批注

对我说一句「想练英语」，我会在你的飞书里建一个今天的文档，给你一个话题，你用英文写给我看。写完告诉我一声，我把批注贴在原句旁边 —— 指出更地道的说法，并说一句为什么。

这种方式叫 Recast，来自真实的语言教学研究：像老师在纸上划一条波浪线，而不是打一个巨大的红叉。
